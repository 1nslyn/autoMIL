<objective>
Implement SCH-02: generic editable-install overlay guard. Two deliverables: (a) `automil check` warns when editable package source paths are snapshotted in `files.editable` without any worktree import guard in place; (b) opt-in daemon-side PYTHONPATH injection in `_launch` when `orchestrator.editable_overlay_guard: true` (default OFF, honoring D-199/D-03 caution).

The check warns loudly; the opt-in guard fixes it at the daemon level for consumers that cannot add a sys.path.insert to their run script. Per D-03 — the D-199/DEC-01 unconditional injection MUST NOT be reinstated.
