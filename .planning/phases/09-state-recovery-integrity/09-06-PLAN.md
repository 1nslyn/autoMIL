      gnode = g.get_node(node_id)

          graph_status = "keep" if composite > p_comp else "discard"

      if raw_status != "partial" and composite > g.meta.get("best_composite", 0.0):

## Trust Boundaries

| archive result.json → terminal_writer | Training-process-written JSON ingested by the framework; schema-validated before graph update |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-11 | Tampering | terminal_writer: graph node update via locked_update; live daemon may also call locked_update concurrently | mitigate | locked_update uses fcntl.flock exclusive lock on .lock file (graph.py:50-63); concurrent writers queue correctly; single-daemon local model means only one writer in normal operation |
| T-09-12 | Tampering | terminal_writer: archive result.json atomic write; crash mid-write leaves .tmp file | mitigate | tempfile+os.replace pattern; .tmp file cleaned up in except block; os.replace is atomic POSIX rename on same filesystem |
| T-09-13 | Tampering | reconcile --from-archive: overwrites executed node state while daemon is live | mitigate | Pitfall 3 guard: skip nodes with status=running; locked_update prevents races with daemon's terminal_writer call |
| T-09-14 | Tampering | terminal_writer: _append_results_tsv opened in append mode; no lock | accept | Single-daemon local model; only one writer; append mode is safe for single-process sequential writes (per existing RESEARCH.md confirmation of the existing pattern) |
| T-09-SC | Tampering | No new packages installed | accept | Pure internal refactor + new Python module; no pip installs |
