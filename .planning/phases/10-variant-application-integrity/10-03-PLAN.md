    Replace the NotImplementedError stub in variant_dispatch.py with the full implementation.

    The function reads the variant selection from applied_variant.json (the file written
    by apply.py Task 2 of plan 10-02). NOT from config.yaml directly. Rationale: config.yaml
    is gitignored and not in the worktree; applied_variant.json IS in the worktree overlay
    (copied by apply_overlay from archive/<node_id>/). The function signature:

      apply_model_variant_to_exp_cfg(exp_cfg, automil_dir: Path) -> None

    Implementation:
    1. Locate applied_variant.json at automil_dir / "applied_variant.json". If it does
       not exist, also try automil_dir / "config.yaml" as fallback and read model.variant
       from there (backward compat for projects not yet using applied_variant.json).
    2. Parse the selection dict: {"model": {"variant": ..., "parent": ...}, ...}
    3. Extract variant_name = selection["model"]["variant"] and parent_name = selection["model"]["parent"].
       If variant_name is None or empty string, return (no-op).
    4. Validate variant_name: Path(variant_name).name == variant_name (no traversal).
    5. variants_root = automil_dir / "variants"
    6. scan_variants(variants_root) to populate MODEL_VARIANTS via @register decorators.
    7. Look up the variant class. Check the exact key format used in MODEL_VARIANTS (read
       _state.py carefully before assuming the key shape — it may be (parent, name) tuple
       or just name). Use that exact key format.
    8. If not found: raise ValueError(f"Variant '{variant_name}' (parent='{parent_name}')
       not found in registry after scanning {variants_root}. Run `automil refresh-registry`.")
    9. clam_args = getattr(variant_cls, "CLAM_ARGS", {}) — optional class attribute.
    10. For each (field, value) in clam_args.items():
        - if hasattr(exp_cfg.model, field): setattr(exp_cfg.model, field, value)
        - elif hasattr(exp_cfg.train, field): setattr(exp_cfg.train, field, value)
        - else: logger.warning("CLAM_ARGS field %r not found in ModelConfig or TrainConfig; skipped", field)
    11. Also check for env var fallback: if applied_variant.json does not exist, check
        os.environ.get("AUTOMIL_VARIANT_MODEL") as a last resort (the env var injected
        by apply.py Task 2 of plan 10-02). If set and variant_name was None, use it as
        variant_name.

    In src/automil/registry/variants/model.py, add a class-level annotation on ModelVariant:
      # Optional: consumer-specific override dict for argument-passing seams.
      # Example (CLAM): CLAM_ARGS: ClassVar[dict] = {"model_size": "big", "dropout": 0.5}
      # The autobench variant_dispatch layer reads getattr(cls, "CLAM_ARGS", {}).
      # No abstract requirement; defaults to {} when absent.
    Do NOT add CLAM_ARGS as an abstractmethod or required attribute — it is optional.
    Import ClassVar from typing (TYPE_CHECKING guard is fine). This is a doc addition only;
    does NOT introduce autobench references into src/automil/ (D-206 preserved).
