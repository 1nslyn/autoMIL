  change the `parent_id` description to read:
  "mil_model: MIL model identifier (normalized: stripped, lowercased, whitespace-collapsed).

  Rename the third parameter from `parent_id: str` to `mil_model: str`. Update the
  format string from `f"{dataset}|{encoder}|{parent_id}"` to `f"{dataset}|{encoder}|{mil_model}"`.
  Add docstring: "mil_model must be pre-normalized via normalize_mil_model() before calling."

  **Change 3 — normalize_mil_model (per D-14):**
  Add after make_cell_id:
  ```
  def normalize_mil_model(raw: str) -> str:
      """Strip, lowercase, collapse internal whitespace (D-14, REC-04).

      Ensures CLAM_SB, clam_sb, ' clam sb ' all hash to the same cell.
      """
      return " ".join(raw.strip().lower().split())
  ```

  **Change 4 — read_cell compat shim (per RESEARCH.md Pitfall 4, D-15):**
  In `read_cell`, add a backward-compatibility shim BEFORE `data["status"] = CellStatus(...)`:
  ```
  # Backward-compat: old cells/*.json have "parent_id"; new cells have "mil_model".
  # This shim must ship with the rename so existing cells load without TypeError.
  if "parent_id" in data and "mil_model" not in data:
      data["mil_model"] = data.pop("parent_id")
  ```
  This is the critical guard from RESEARCH.md Pitfall 4. It must be present so that
  Plan 05's `automil cells migrate` command can read old cells to re-key them.

  Do NOT change write_cell, list_cells, or any other function.
  Do NOT change the CellStatus enum.
