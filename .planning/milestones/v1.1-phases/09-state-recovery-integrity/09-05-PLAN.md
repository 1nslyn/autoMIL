  dry_run: bool = False) -> list[dict]`.

  Implementation (from 09-PATTERNS.md §migrate.py and RESEARCH.md D-15 algorithm):
  1. Normalize mil_model via normalize_mil_model.
  2. Iterate `sorted(cells_dir.glob("*.json"))`. Skip malformed files with logger.warning
     (mirror registry.py:122-146 malformed-file guard pattern).
  3. For each cell, compute `new_id = make_cell_id(cell.dataset, cell.encoder, mil_model_norm)`.
  4. If `new_path == path` (cell already uses the correct key — coincidental match or already
     migrated), log and skip.
  5. If `new_path` exists and `new_path != path` (merge case):
     - If `cell.mode == "agent_active"`: existing_cell.consumed_active_seconds + cell.consumed_active_seconds.
     - If wall_clock (or any other mode): keep the cell with the earliest started_at; discard
       the other's started_at.
     - Write merged cell first (atomic write_cell), then unlink old path.
  6. If `new_path` does not exist (rename case):
     - Create new_cell = dataclasses.replace(cell, cell_id=new_id, mil_model=mil_model_norm).
     - Write new cell first (atomic), then unlink old if old != new (safe rename).
  7. Append summary dict {"old_id": ..., "new_id": ..., "action": "merge"|"rename"|"skip"} for each.
  8. Return summary list.

  dry_run=True: skip all write_cell and path.unlink calls; return summaries only.

  Use `import dataclasses` for `dataclasses.replace`. Use `from automil.cells.state import
  Cell, make_cell_id, normalize_mil_model, read_cell, write_cell`.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| --mil-model CLI flag → cell_id hash | Operator-supplied model name; normalized before hashing |
| propose metadata → submit resolution | Graph node metadata from a prior propose call; may be stale |
| cells/*.json iteration → file deletion | migrate_cells deletes old cell files; atomic write-first pattern required |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-08 | Elevation of Privilege | cells/migrate.py: double-count of consumed_active_seconds on merge | mitigate | Mode-aware merge: agent_active sums consumed_active_seconds; wall_clock keeps min(started_at). Both paths explicitly tested in test_migrate.py |
| T-09-09 | Tampering | cells/migrate.py: old cell file deleted before new cell written could leave budget state inconsistent on crash | mitigate | Write new cell file first (atomic tempfile+replace), then delete old. If write fails, old file is still present. No partial state on crash. |
| T-09-10 | Tampering | --mil-model CLI injection via model name → filesystem path | accept | normalize_mil_model produces a lowercase string; make_cell_id hashes it to a 16-char hex digest; the digest is the only thing used as a path component; the raw model name is never used in a filesystem or shell context |
| T-09-SC | Tampering | No new packages installed | accept | Pure Python stdlib + existing automil modules; no pip installs |
</threat_model>
