  ```python
  def _handle_timeout(self, exp_id: str) -> None:
      """D-04 (REC-01): SIGTERM main PID first (flush handler runs), then SIGKILL process
      group after configurable grace window. LOCAL BACKEND ONLY — SLURM and Ray backends
      handle their own timeout signals and never call this method."""
      exp = self.running[exp_id]
      pid = exp.process.pid
      grace = int((self.config.get("orchestrator") or {}).get("timeout_grace_seconds", 10))
      logger.warning(
          "Timeout for %s: SIGTERMing main PID %d (grace=%ds before SIGKILL group)",
          exp_id, pid, grace,
      )
      try:
          os.kill(pid, signal.SIGTERM)    # main PID only — lets flush handler run
      except ProcessLookupError:
          pass
      time.sleep(grace)
      if exp.process.poll() is None:
          try:
              os.killpg(os.getpgid(pid), signal.SIGKILL)
          except ProcessLookupError:
              pass
      self._timed_out[exp_id] = True
      self._handle_completion(exp_id, returncode=-9)
  ```

  Ensure `signal` is already imported at the top of the module (it is — grep confirms).
  `time` stdlib is also already imported. No new imports needed.

  PID reuse safety note (STRIDE T-09-05): `os.kill(pid, SIGTERM)` sends to whatever process
  holds that PID at the moment of the call. In the local backend, `exp.process` (Popen) holds
  a reference to the process — if it has already exited, `ProcessLookupError` is caught.
  The process group kill uses `os.getpgid(pid)` which also raises `ProcessLookupError` on
  dead PID. Both are guarded. No additional mitigation needed at ASVS L1.

|----------|-------------|
| AUTOMIL_RESULTS_DIR env var → filesystem write | Env var content becomes a Path; untrusted if the environment is compromised |
| orchestrator → training process (os.kill) | Daemon sends SIGTERM to a PID; PID reuse is a known OS risk |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-05 | Tampering | _handle_timeout: os.kill(pid, SIGTERM) — PID reuse risk | mitigate | ProcessLookupError caught on both os.kill and os.killpg calls; Popen holds a reference keeping the PID alive until poll() confirms exit; local-backend-only so the PID is always a child of the orchestrator process |
| T-09-06 | Tampering | AUTOMIL_RESULTS_DIR path used as write target in flush handler | mitigate | Validate target.is_absolute() before use; fall back to Path.cwd() for relative or missing values; path is never used as a command argument — only as a parent dir for result.json write |
| T-09-07 | Denial of Service | _collect_or_synthesize_result — archive.glob("fold_*_result.json") on large archives | accept | glob is bounded by the number of folds (typically 5-10); no O(n) risk; local filesystem only |
| T-09-SC | Tampering | No new packages installed | accept | Pure stdlib changes; no pip installs |
