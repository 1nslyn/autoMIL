<objective>
OPS-01: extend cancel.py to kill daemon-launched local jobs directly using on-disk
pid/pgid metadata when no opaque_id is present in the running spec.

Purpose: When the daemon launches a local job it writes the process pid, pgid, and
(on Linux) starttime_ticks into `orchestrator/running/local/<node>.json`. A fresh CLI
process cannot use backend.cancel() → _kill_experiment() because that path requires the
daemon's in-memory self.running map (always empty in a fresh CLI process). The fix reads
the metadata directly from disk and sends os.killpg, PID-reuse-guarded by the established
_is_pid_alive_with_starttime helper.

Output: cancel.py with a direct-kill branch; test_cancel_local_direct_kill GREEN.
</objective>

**Part B — add direct-kill branch immediately after Part A**

Insert a conditional that fires when `not opaque_id` (i.e. direct-kill path needed).
This replaces Steps 5-7 (backend instantiation + backend.cancel + poll loop) for the

```python
if not opaque_id:
    # Direct-kill path (OPS-01 / D-01): signal the process group from the CLI using
    # on-disk metadata. The daemon's in-memory self.running is empty in a fresh CLI
    # process, so routing through backend.cancel() + _kill_experiment() is a no-op.
    import os as _os
    import signal as _signal
    from automil.orchestrator import (  # noqa: PLC0415
        _is_pid_alive_with_starttime,
        _read_proc_starttime,
    )

    def _is_alive(pid: int, st: int | None) -> bool:
        """PID-reuse-safe liveness check. Falls back to os.kill probe on non-Linux."""
        if st is not None:
            return _is_pid_alive_with_starttime(pid, st)
        try:
            _os.kill(pid, 0)
            return True
        except (ProcessLookupError, PermissionError):
            return False

    if not _is_alive(_pid, _starttime):
        # Process already gone — skip signalling, proceed to graph update.
        logger.debug("cancel: process %d already gone, skipping kill", _pid)
    else:
        # SIGTERM first (per D-Claude's-discretion: mirror daemon's SIGTERM→grace→SIGKILL).
        try:
            _os.killpg(_pgid, _signal.SIGTERM)
            logger.debug("cancel: sent SIGTERM to pgid %d for %s", _pgid, node_id)
        except (ProcessLookupError, PermissionError):
            pass

        # 5-second grace period (mirrors daemon's _pending_sigkill_at pattern).
        _grace_deadline = time.monotonic() + 5.0
        while time.monotonic() < _grace_deadline and _is_alive(_pid, _starttime):
            time.sleep(0.2)

        if _is_alive(_pid, _starttime):
            # Grace elapsed — escalate to SIGKILL.
            try:
                _os.killpg(_pgid, _signal.SIGKILL)
                logger.debug("cancel: sent SIGKILL to pgid %d for %s", _pgid, node_id)
            except (ProcessLookupError, PermissionError):
                pass
            # Brief wait for SIGKILL to land.
            for _ in range(10):
                if not _is_alive(_pid, _starttime):
                    break
                time.sleep(0.1)

        if _is_alive(_pid, _starttime):
            raise click.ClickException(
                f"Could not kill process group {_pgid} for node {node_id!r} after "
                f"SIGTERM + SIGKILL. Manage the process manually."
            )

    # Fall through to graph update + archive move (Steps 8-10 below — shared path).

else:
    # opaque_id present: existing backend.cancel() + poll path (Steps 5-7 — UNCHANGED).
    ...existing Steps 5-7 code...
```
