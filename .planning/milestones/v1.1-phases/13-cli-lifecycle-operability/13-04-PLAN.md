**File 1: src/automil/cli/_helpers.py — add _PROJECT_OVERRIDE and override hook (D-08)**

Add a module-level variable immediately before the `_find_automil_dir` function definition.
The type annotation uses a string literal to avoid importing Path at module level (it is
already imported via `from pathlib import Path`):

```python
# Module-level project override set by the --project group option on `main`.
# None = use cwd walk (default behaviour).
# Path = use this path for project discovery (set by main() callback before any subcommand).
# Tests must reset this to None in teardown via monkeypatch.setattr to prevent bleed.
_PROJECT_OVERRIDE: Path | None = None
```

Modify `_find_automil_dir()` to consult `_PROJECT_OVERRIDE` before falling through to the
existing cwd walk. Add the check as the FIRST thing in the function body (before the
`p = Path.cwd()` line):

```python
def _find_automil_dir() -> Path:
    """Walk up from cwd to find a directory containing automil/config.yaml.

    Honors _PROJECT_OVERRIDE when set by the --project group option before
    falling through to the cwd walk.

    Returns the ``automil/`` directory itself.
    """
    if _PROJECT_OVERRIDE is not None:
        # Accept either: (a) project root (parent of automil/) or (b) automil/ dir itself.
        for candidate in (_PROJECT_OVERRIDE / "automil", _PROJECT_OVERRIDE):
            if (candidate / "config.yaml").exists():
                # Always normalise: return the automil/ dir.
                return candidate if candidate.name == "automil" else candidate / "automil"
        raise click.ClickException(
            f"--project {_PROJECT_OVERRIDE}: no automil/config.yaml found under "
            f"{_PROJECT_OVERRIDE}. Point --project at the project root or the "
            f"automil/ dir directly."
        )
    # Existing cwd walk — unchanged:
    p = Path.cwd()
    while p != p.parent:
        candidate = p / "automil" / "config.yaml"
        if candidate.exists():
            return p / "automil"
        p = p.parent
    raise click.ClickException(
        "No automil/config.yaml found. Run 'automil init' in your project root."
    )
```

The rest of _helpers.py (_find_git_root, _load_technique_map, _matches_scope) is

Modify the `@click.group()` + `def main()` block. Add a `@click.option` decorator for

```python
    """autoMIL: Autonomous agent-driven MIL model improvement."""

```

With:
```python
@click.group()
@click.option(
    "--project",
    "project_path",
    default=None,
    type=click.Path(exists=True),
    metavar="PATH",
    help=(
        "Path to project root (containing automil/config.yaml) or the automil/ dir. "
        "Overrides cwd-based project discovery for all subcommands. "
        "Use this when running automil from outside the project root."
    ),
    is_eager=True,
)
def main(project_path: str | None = None):
    """autoMIL: Autonomous agent-driven MIL model improvement."""
    # Activity signal (P2.1): every automil invocation is an agent action.
    # Stamp the project-level marker so the activity-gated budget counts CLI
    # work too — and so runtimes without Claude Code's PostToolUse hook (codex,
    # opencode) still register activity. Best-effort: never break a command if
    # we're not inside a project or the marker can't be written.
    import automil.cli._helpers as _h  # noqa: PLC0415
    if project_path is not None:
        from pathlib import Path as _Path  # noqa: PLC0415
        _h._PROJECT_OVERRIDE = _Path(project_path).resolve()
    try:
        from automil.cli._helpers import _find_automil_dir  # noqa: PLC0415
        from automil.cells.activity import touch_last_action  # noqa: PLC0415
        touch_last_action(_find_automil_dir())  # now respects _PROJECT_OVERRIDE
    except Exception:
        pass
```

Key points:
- `click.Path(exists=True)` means Click validates the path exists before invoking main;
  nonexistent paths are rejected at the Click layer with a clean error (ASVS V5 / path
  traversal mitigation per 13-RESEARCH.md §Security Domain).
- `is_eager=True` ensures the group option is processed before any subcommand options
  (important for the discovery seam to be set before any command calls _find_automil_dir).
- `import automil.cli._helpers as _h` is inside the function body (lazy import per D-69).
- The `Path(project_path).resolve()` converts to an absolute path, eliminating relative
  traversal. The `click.Path(exists=True)` guard already ensures the path exists.
- No other changes to __init__.py in this task. (dequeue registration from plan 13-03
