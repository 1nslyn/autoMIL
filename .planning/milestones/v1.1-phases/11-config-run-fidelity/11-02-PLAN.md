<objective>
Fix CFG-01 (D-01): change the six training-override argparse defaults in run_experiment.py from hard-coded values to None, and change the TrainConfig/ExperimentConfig construction to only pass values that were explicitly supplied on the CLI.

After this fix, dataclass defaults are authoritative when the caller doesn't explicitly pass the flag.
