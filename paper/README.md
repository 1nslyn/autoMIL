# paper/

Planning material for the autoMIL/autobench paper. Two phases, kept in
separate folders since they have different scope, timeline, and (mostly)
different open questions:

- **[`shared/BACKGROUND.md`](shared/BACKGROUND.md)** — context common to both
  phases: target venue/strategy, the two layers of the project (framework vs.
  empirical), the empirical trajectory so far (Phases A–C), and the full
  cluster data inventory. Read this first.
- **[`preprint/PLAN.md`](preprint/PLAN.md)** — Phase 1, **active**. The
  confirmed pivot: reduced dataset/model scope, competitive positioning vs.
  PathBench-MIL and the Frontiers embedding-choice paper, and the two
  capability gaps that were triaged — **TITAN is in the preprint; regression
  is deferred to Phase 2**.
- **[`preprint/EXPERIMENT_GRID.md`](preprint/EXPERIMENT_GRID.md)** — Phase 1,
  **authoritative on counts**. The verified grid (33 exps/dataset, 165 total,
  825 fold-trainings), compute estimates, and the figure plan. Where any other
  doc disagrees on a number, this one wins.
- **[`preprint/EXECUTION_PLAN.md`](preprint/EXECUTION_PLAN.md)** — Phase 1,
  the compute campaign. Note its §0/§0b/§1 are a **2026-07-03 audit snapshot**
  kept for provenance; the roster and the TITAN build have both moved on since.
- **[`journal/PLAN.md`](journal/PLAN.md)** — Phase 2, **provisional**. The
  full-scope Nature BME submission. Deliberately thin right now — revisit
  after the preprint ships.
- **[`references/`](references/)** — raw source material, archived verbatim:
  the older Notion proposal doc.
