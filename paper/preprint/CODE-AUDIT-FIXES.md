Predeclared per cohort (O2: δ≈0.05 on GBM/PDAC, ≈0.015 on LUAD/LGG/HNSC; `se_multiplier: 1.0`). **Stated in the code, not implied:** this is a conservative single-arm screen, NOT a test — parent and child share folds, so the paired inference stays in the Stage-B gate. 40 new tests; 1296 automil + 747 autobench green. |
