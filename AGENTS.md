# AGENTS.md

autoMIL is an autonomous experiment framework for Multiple Instance Learning in computational pathology. A coding agent iteratively improves a model in an existing ML repository, and every attempt is recorded in a persistent experiment tree.

The agent instructions for this repository are in [CLAUDE.md](CLAUDE.md). Read that file before making changes.

This file is for the autoMIL source repository. The `AGENTS.md` that `automil init` writes into a user project is a different file, rendered from `src/automil/agent_assets/_shared/AGENTS.md`.
